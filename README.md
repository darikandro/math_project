### Тема проекта
Сайт-тренажер по математике.

Предоставляет возможность решать математические задачи разных уровней сложности, проверять свое решение и отслеживать прогресс.

### Версии
* Python 3.14.0 
* Flask 3.1.2

### Установка зависимостей
pip install -r requirements.txt

### Применение миграций
flask db upgrade

### Запуск проекта
python app.py

### URL проекта
http://127.0.0.1:5000/  - главная
